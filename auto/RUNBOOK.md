# RUNBOOK — คลิปเทรนด์อัตโนมัติ (วันละ 2 รอบ)

> ไฟล์นี้คือคำสั่งของ **งานตามเวลา (scheduled task)** แต่ละรอบ — Claude อ่านแล้วทำตามตั้งแต่ต้นจนจบ **โดยไม่มีคนรออยู่**
> ห้ามถามผู้ใช้ระหว่างทาง: ตัดสินใจเองแบบระมัดระวัง แล้วเขียนเหตุผลไว้ในไฟล์ (ผู้ใช้ตรวจก่อนโพสต์เองทุกคลิป)
> Claude ทำแค่ส่วน "คิด/เขียน" (ข้อ 1–8) แล้ว push → **GitHub Actions** (`.github/workflows/auto-render.yml`) สร้างภาพ AI + เสียง + เรนเดอร์ + ปก + แพ็กไฟล์ให้เอง
> เครื่องผู้ใช้ดึงไฟล์ลงโฟลเดอร์ด้วย `auto/windows/sync-clips.ps1`

กติกาเดิมทั้งหมดใน `CLAUDE.md` และ `rules/` ยังใช้ ยกเว้น **ไม่มี checkpoint ระหว่าง stage** (ไม่ต้องรอใครอนุมัติ) — checkpoint เดียวคือผู้ใช้ดูคลิปก่อนโพสต์

## 0. เตรียม (≤ 2 นาที)
1. repo `pandora2544/storyteller-with-claude` ต้องอยู่ในเซสชัน (add_repo แบบ push แล้ว clone) · `git pull` ให้เป็นล่าสุด
2. รอบนี้คือ `am` (เช้า) หรือ `pm` (เย็น) ตามที่ prompt ของงานบอก · วันที่ใช้เวลาไทย
3. `node scripts/auto/new-slot.mjs <am|pm>` → ได้ `slug` (เช่น `d-20261109-am`) + เวลาโพสต์ + หัวข้อ 14 วันล่าสุด
4. ถ้า `projects/<slug>/shots.json` มีอยู่แล้ว (อีกบัญชีทำไปแล้ว/รอบซ้ำ) → **หยุด** รายงานว่ามีแล้ว
5. `node scripts/lib/settings.mjs <slug>` → งบตัวอักษร/ช็อต/beat · อ่าน `presets/voices/<voice>.md` (persona)

## 1. หาเทรนด์ (≤ 10 นาที)
แหล่ง (ใช้ WebSearch / WebFetch):
- Google Trends ไทย: `https://trends.google.com/trending/rss?geo=TH` (สิ่งที่คนไทยค้นวันนี้)
- ข่าวไทย: Thai PBS, BBC News ไทย, ไทยรัฐ, มติชน, ประชาชาติธุรกิจ, The Standard · ข่าวโลก: Reuters, AP, BBC
- หัวข้อที่คนพูดถึงบนโซเชียล (ค้น "กระแส" / "ดราม่า" / "ไวรัล" + วันที่วันนี้)

คัด **5 หัวข้อ** แล้วให้คะแนน 1–5 ในแต่ละข้อ — เลือกตัวที่รวมสูงสุด:
| เกณฑ์ | ความหมาย |
|---|---|
| กระแส | คนกำลังค้น/พูดถึง *วันนี้* (ไม่ใช่ข่าวเก่า) |
| ใกล้ตัวคนไทย | ตอบได้ว่า "แล้วคนไทย/เราได้อะไร เสียอะไร" — **มุมนี้คือเอกลักษณ์ของช่อง** |
| อธิบายได้ใน 60 วิ | มีคำถามเดียวที่ตอบจบในคลิป |
| ยืนยันได้ | มีแหล่งน่าเชื่อถือ ≥ 2 แหล่งสำหรับข้อเท็จจริงหลัก |
| ไม่ซ้ำ | ไม่ซ้ำหัวข้อ/มุมใน 14 วันล่าสุด · ไม่ซ้ำกับรอบเช้าของวันเดียวกัน |

เทรนด์ทุกหมวดได้ (ข่าว เศรษฐกิจ เทคโนโลยี วิทยาศาสตร์ บันเทิง กีฬา สุขภาพทั่วไป ท่องเที่ยว ประวัติศาสตร์ที่กลับมาเป็นกระแส) — สลับหมวดไม่ให้ซ้ำกันหลายวันติด

### ห้ามทำ (เลือกหัวข้ออื่นแทน)
- สถาบันพระมหากษัตริย์ทุกแง่มุม (ความเสี่ยงทางกฎหมายไทยสูง)
- ข่าวลือ/ข้อมูลที่ยังไม่มีแหล่งหลักยืนยัน · "คลิปหลุด" · ข่าวจากเพจเดียว
- เหตุร้ายที่มีผู้เสียหายเป็นบุคคลธรรมดา (ระบุตัวได้), เด็ก, ความรุนแรงแบบโจ่งแจ้ง, การฆ่าตัวตาย
- ชี้นำการเลือกตั้ง/พรรค/นักการเมือง · โจมตีศาสนา/ชาติพันธุ์ · หมิ่นประมาทบุคคลจริง
- คำแนะนำการแพทย์/การลงทุนเฉพาะตัว ("ควรซื้อหุ้นตัวนี้", "หยุดยา")
- หวย/การพนัน · โฆษณาแฝงสินค้า

### หัวข้ออ่อนไหว (สงคราม ภัยพิบัติ การเมืองโลก เศรษฐกิจถดถอย) — ทำได้ แต่:
- แยก **"เกิดแล้ว" กับ "อาจเกิด"** ชัดเจนในบท: ใช้ "นักวิเคราะห์มองว่า…", "ถ้า…ก็อาจ…" ห้ามพูดการคาดการณ์เป็นข้อเท็จจริง
- ผลกระทบต่อไทยต้องมีแหล่ง (ธปท., สภาพัฒน์, กระทรวงพาณิชย์, กรมการค้าต่างประเทศ, สำนักข่าวหลัก) หรือพูดเป็นกลไกทั่วไปที่อธิบายได้ ("ไทยนำเข้าน้ำมันเกือบทั้งหมด → ราคาน้ำมันโลกขึ้น = ค่าครองชีพขึ้น")
- ไม่ปลุกความกลัว ไม่ใช้คำว่า "สงครามโลกครั้งที่ 3 มาแล้ว" ฯลฯ — hook แรงได้ด้วยคำถาม ไม่ใช่ด้วยการขู่
- ภาพ: ไม่มีภาพเหมือนจริงของการสู้รบ/ผู้บาดเจ็บ · ใช้แผนที่ กราฟ ไอคอน และภาพประกอบสไตล์การ์ตูน

## 2. ค้นข้อมูล → `facts.md` (≤ 15 นาที)
- ตาราง `| F-01 | ข้อเท็จจริง | ความมั่นใจ (สูง/กลาง/ต่ำ) | [แหล่ง](URL) · วันที่ของข่าว |` — แหล่งต้องเป็นลิงก์ (ระบบดึงไปทำ "ที่มา")
- ตัวเลข/ข้อเท็จจริงหลักทุกตัว ≥ 2 แหล่งที่ไม่ได้ลอกกัน · ตัวเลขขัดกัน → ใช้แบบกันไว้ ("ราว", "กว่า") แล้วจดไว้
- ท้ายไฟล์: `## ต้องเช็กก่อนโพสต์` — ข้อที่ความมั่นใจกลาง/ต่ำ หรือเป็นข่าวที่กำลังเปลี่ยน (ผู้ใช้จะเห็นใน README ของแพ็ก)
- ห้ามคัดลอกข้อความข่าวยาว ๆ — สรุปด้วยคำของเราเอง

## 3. `brief.md` + `script.md` (≤ 10 นาที)
- โครงคลิปสั้น 60 วิ (rule 02): hook ≤ 3 วิ เป็น **คำถาม** ที่คนไทยอยากรู้คำตอบ → setup → act1–3 (reveal 3 ครั้ง) → payoff ตอบ hook → outro เป็น loop line โยงกลับประโยคแรก
- งบตัวอักษรจาก `settings.mjs` (**ห้ามเกิน `chars.max`** — เสียงช่องนี้พูดช้ากว่า preset; ยาวเกิน = คลิปเกิน 75 วิ)
- persona `doc-narrator-female`: สรรพนาม "เรา" · ไม่มีคำลงท้าย · ห้าม ครับ/ค่ะ/คุณผู้ชม · ห้ามทักทาย/ขอไลก์/ขอติดตาม
- `voTTS`: ตัวเลขเป็นคำอ่าน, ชื่อต่างประเทศสะกดตามเสียงไทย, `…` เว้นจังหวะ

## 4. ภาพ → `images.json` (ภาพ AI) + คลัง vector เดิม
ทุกหัวข้อใหม่ไม่มี vector วาดไว้ → **ใช้ภาพ AI เป็นหลักของภาพประกอบ** + ของในโค้ดสำหรับข้อมูล
- `images.json` 4–6 รูป (cutout: ขอให้ "on a plain flat light-gray background" — ระบบลบพื้นให้เอง): `plate` ฉากหลัง 9:16 2–3 รูป + `cutout` สิ่งของ/สัญลักษณ์ 2–3 รูป · `"variants": 1` (ระบบเลือกรูปแรกอัตโนมัติ)
- prompt ภาษาอังกฤษ บรรยายสิ่งของ/ฉาก **สไตล์ภาพประกอบแบน การ์ตูน** (style preset เติมสไตล์ให้เอง) · ห้ามใบหน้าบุคคลจริง ห้ามโลโก้แบรนด์ ห้ามภาพสมจริงของเหตุการณ์จริง ห้ามธงชาติที่ผิดแบบ (ถ้าไม่แน่ใจ อย่าใส่ธง)
- ใน shots.json: `"asset": "img:<id>|<vector สำรอง>"` — vector สำรองต้องอยู่ในทะเบียน `src/assets/index.ts` (เช่น `bg-color`, `paper-bg`, `earth-globe`, `phone-feed`, `coin-stack`, `price-tag`, `calendar-year`, `signal-icon`, `balance-scale`, `question-split`, `spotlight-stage`, `giant-pin`, `vote-hands`) — ถ้าสร้างภาพไม่สำเร็จ คลิปยังออกได้
- **ข้อมูลใช้ของในโค้ดเสมอ** (`data`): `map` (ภูมิศาสตร์/เส้นทาง/จุดเกิดเหตุ — พิกัด [lon, lat]), `bar`, `counter`, `unit` · ข้อความบนจอใช้ `text`
- ไม่ต้องเขียน asset .tsx ใหม่ (เสี่ยงคอมไพล์พังตอนเรนเดอร์อัตโนมัติ)

## 5. `shots.json` (≤ 15 นาที)
- schema ตาม rule 09 · `meta.slug` = slug · 1080×1920 · `era: "present"` (หรือยุคที่เหมาะถ้าเล่าย้อนอดีต ≤ 2 ยุค)
- ช็อต 1.4–2.4 วิ ตามงบ · ภาพแรกขยับตั้งแต่เฟรมแรก · ข้อความบนจออยู่ y 250–1150 (ซับอยู่ y≈1300)
- `sources` ใน shots.json: ทุก `sourceRef` ต้องมีใน facts.md
- **จัดวางให้ซับไม่ทับภาพ:** ซับอยู่ที่จอ y≈1180–1420 → พระเอกของช็อต (subject/cutout) วางกลางที่ world `y` ≤ 0 และขอบล่างของรูปต้องไม่ลงไปเกิน world `y` ≈ +180 (ขนาด `w` ≤ 620) · พื้นที่ล่างจอเว้นไว้ให้ซับ
- **ทุกช็อตต้องมีภาพหลัก 1 อย่าง** นอกจากตัวหนังสือ (ไอคอน/รูป AI/แผนที่/กราฟ) — ห้ามช็อตที่มีแค่ตัวหนังสือบนพื้นเปล่า
- ตัวหนังสือบนจอห้ามซ้ำกับซับคำต่อคำ — ใช้เป็นคีย์เวิร์ด/ตัวเลขสั้น ๆ (≤ 4 คำ) · ตัวเลขบนจอต้องตรงกับที่พูด
- `covers`: 1–2 แบบ (`A`, `B`) — หัวข้อ ≤ 2 บรรทัด บรรทัดละ ≤ 8 ตัวอักษร · ตัวเลขบนปกต้องมี sourceRef · ไม่หลอกคลิก

## 6. `post.json` — แคปชันที่ช่วยให้ไวรัล (เฉพาะ `tiktok`, `facebook`, `instagram`)
- **บรรทัดแรก = ตะขอ** ต่อจาก hook ในคลิป (ไม่ซ้ำคำ) — คำถาม/ตัวเลขที่ทำให้หยุดเลื่อน · ≤ 60 ตัวอักษร
- บรรทัด 2–3: สิ่งที่คนดูจะได้ ("ดูจบจะรู้ว่า…") **ไม่สปอยล์คำตอบ**
- ปิดด้วย **คำถามชวนคอมเมนต์** ที่ตอบง่าย (เลือก A/B, "ใครเคย…", "คิดว่า…ไหม") — คอมเมนต์ช่วยการกระจายมากที่สุด
- แฮชแท็ก: TikTok 3–5 · IG ≤ 5 · FB 2–3 → สูตร **1 กว้างที่คนไทยค้น** (`ข่าววันนี้` / `รู้หรือไม่` / `สาระน่ารู้`) + **2–3 เฉพาะเรื่อง** (ชื่อเหตุการณ์/คีย์เวิร์ดที่กำลังเทรนด์ใน Google Trends) + **1 หมวด** (`เศรษฐกิจ` / `เทคโนโลยี` …) · ห้ามแท็กดังที่ไม่เกี่ยว (#fyp ซ้ำ ๆ ไม่ช่วยและดูสแปม — ใส่ได้อย่างมาก 1)
- อีโมจิ ≤ 2 · Facebook ใส่ `{{sources}}` · TikTok/IG ใส่ที่มาย่อ 1–2 แหล่ง
- `aiDisclosure`: `false` เมื่อภาพเป็นการ์ตูน + TTS เล่าเรื่อง · `true` ถ้ามีภาพที่ดูเหมือนจริง · เขียนเหตุผลใน `notes`
- `node scripts/post.mjs <slug>` ต้องขึ้น `✓ post ผ่าน`

## 7. ตรวจ
- `node scripts/validate.mjs projects/<slug>` ต้องขึ้น `✓ validate ผ่าน` — ไม่ผ่านแก้จนผ่าน (ห้าม push ของที่ไม่ผ่าน)
- อ่านบทออกเสียงในใจ 1 รอบ: hook ถูกตอบใน payoff? มีประโยคไหนพูดการคาดเดาเป็นข้อเท็จจริง?

## 8. บันทึก + ส่งไปเรนเดอร์
1. ต่อท้าย `auto/history.jsonl` 1 บรรทัด: `{"date":"YYYY-MM-DD","slot":"am","slug":"…","title":"…","category":"…","trend":"ทำไมเป็นกระแสวันนี้ (สั้น)","account":"Knight|Knight2"}`
2. `git add projects/<slug> auto/history.jsonl` → `git commit -m "auto: <slug> <ชื่อเรื่อง>"` → `git pull --rebase` → `git push`
3. push แล้ว Actions เริ่มเอง (ใช้เวลา ~10–20 นาที) — ไม่ต้องรอ

## 9. รายงาน (ข้อความสุดท้ายของงาน)
3–5 บรรทัด: ชื่อเรื่อง · ทำไมเลือก (กระแส + มุมไทย) · เวลาโพสต์แนะนำ · ข้อที่ต้องเช็กก่อนโพสต์ · ลิงก์ Actions `https://github.com/pandora2544/storyteller-with-claude/actions`

## ถ้าติดขัด
